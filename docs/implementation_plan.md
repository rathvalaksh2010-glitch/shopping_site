Recommended implementation order

Phase 1 — Foundation

Flask app factory, configuration, database, migrations, models, base template, and shop settings.

Phase 2 — Authentication

Registration, login, logout, password hashing, account ownership, and role-based access.

Phase 3 — Products and inventory

Categories, product listings, images, admin CRUD, stock adjustments, and inventory history.

Phase 4 — Cart and checkout

Cart persistence, price calculation, address management, order transactions, and payment integration if required.

Phase 5 — Security and launch

Automated tests, privacy and terms pages, production deployment, HTTPS, backups, and security review.
